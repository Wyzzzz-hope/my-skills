# 京东(JD)平台 · 与拼多多差异交互点

**对比基准**: PDD（拼多多）平台交互文档
**差异说明**: 仅列出与PDD不同的交互点，相同的交互不列举

---

## 一、筛选区 - 缺少的交互

### ❌ 无「筛选」按钮弹窗

**PDD有，京东无**

PDD的相关交互：
- 交互1：点击「筛选」按钮打开全屏弹窗
- 交互6：点击弹窗中「确认」按钮
- 交互7：点击弹窗内「更多」Tag
- 交互8：点击弹窗内「收起」按钮

**京东说明**：所有筛选项直接在筛选栏中横向滚动展示，无独立的全屏筛选弹窗。

---

## 二、商品瀑布流 - 新增的交互

### ✅ 新增交互1：点击商品图片跳转外部详情页

| 字段 | 内容 |
|------|------|
| **触发元素** | 商品图片 |
| **事件** | `onClick` |
| **代码位置** | `JDItem.tsx:425` |
| **行为** | 在新标签页打开京东商品详情外部链接 |

**与PDD的区别**：
- PDD：点击商品卡片选中商品，不跳转
- 京东：点击商品图片直接跳转京东外部链接

---

### ✅ 新增交互2：点击店铺「进店>」按钮

| 字段 | 内容 |
|------|------|
| **触发元素** | 店铺区域的「进店>」文字按钮 |
| **事件** | `onClick` |
| **代码位置** | `JDItem.tsx:468` |
| **行为** | 在新标签页打开京东店铺外部链接 |

**与PDD的区别**：
- PDD：无店铺跳转按钮
- 京东：有「进店>」按钮，点击跳转京东店铺

---

## 三、商品瀑布流 - 缺少的交互

### ❌ 无商品详情浮层

**PDD有，京东无**

PDD的相关交互（共9个）：
- 交互5：商品详情浮层打开（自动加载数据）
- 交互6：切换商品图片（左箭头）
- 交互7：切换商品图片（右箭头）
- 交互8：点击底部按钮打开 SKU 面板
- 交互9：SKU 面板点击关闭按钮
- 交互10：SKU 面板点击规格选项
- 交互11：SKU 面板点击「确定」按钮
- 交互12：详情页点击右上角关闭按钮
- 交互14：点击图片轮播指示器小圆点

**京东说明**：京东没有内部详情浮层功能，所有商品信息直接在卡片上展示，通过外链跳转查看详情。

---

### ❌ 无悬停浮层交互

**PDD有，京东无**

PDD的相关交互：
- 交互3：悬停商品卡片后点击「查看商品详情」浮层（双栏）
- 交互4：悬停商品卡片后点击「查看商品详情」浮层（单栏）

**京东说明**：京东商品卡片无悬停展示「查看商品详情」浮层的功能。

---

## 总结

**京东与拼多多的核心交互差异**：

| 区域 | 京东 | 拼多多 |
|-----|------|--------|
| 筛选区弹窗 | ❌ 无 | ✅ 有红色「筛选」按钮弹窗 |
| 商品点击行为 | ✅ 跳转外部链接 | ✅ 打开内部详情浮层 |
| 店铺跳转 | ✅ 有「进店>」按钮 | ❌ 无 |
| 商品详情浮层 | ❌ 无 | ✅ 有完整浮层（图片轮播、SKU选择） |
| 悬停浮层 | ❌ 无 | ✅ 有「查看商品详情」浮层 |
