# 淘宝(online/log)平台 · 与拼多多差异交互点

**对比基准**: PDD（拼多多）平台交互文档
**差异说明**: 仅列出与PDD不同的交互点，相同的交互不列举
**平台标识**: `envType === 'online'` 或 `envType === 'log'`

---

## 一、筛选区 - 新增的交互

### ✅ 新增交互1：点击筛选子选项面板的「关闭」按钮

| 字段 | 内容 |
|------|------|
| **触发元素** | 筛选子选项弹出面板右上角的「×」关闭图标 |
| **事件** | `onClick` |
| **代码位置** | `FilterCardHeader/index.tsx:569` |
| **行为** | 关闭当前展开的筛选子选项面板 |

**与PDD的区别**：
- PDD：子选项面板没有关闭按钮，只能通过点击遮罩层或重新点击筛选标签关闭
- 淘宝：子选项面板右上角有独立的「×」关闭按钮

---

### ✅ 新增交互2：点击全部筛选弹窗的「关闭」按钮

| 字段 | 内容 |
|------|------|
| **触发元素** | 全部筛选弹窗顶部右侧的「×」关闭图标 |
| **事件** | `onClick` |
| **代码位置** | `FilterCardHeader/index.tsx:616` |
| **行为** | 关闭全部筛选弹窗 |

**与PDD的区别**：
- PDD：弹窗通过「确认」按钮关闭
- 淘宝：弹窗有独立的「×」关闭按钮

---

## 二、筛选区 - 独有的交互模块

### ✅ 店铺卡片模块

| 字段 | 内容 |
|------|------|
| **功能** | 展示与搜索相关的店铺信息卡片 |
| **代码位置** | `FilterCardHeader/index.tsx:724` |
| **展示位置** | 筛选区上方 |

**说明**：淘宝平台在筛选区上方有独立的店铺卡片展示区域，PDD和京东均无此功能模块。

---

## 三、商品瀑布流 - 新增的交互

### ✅ 新增交互1：点击商品卡片上的「跳转」按钮

| 字段 | 内容 |
|------|------|
| **触发元素** | 商品卡片上的跳转图标区域 |
| **事件** | `onClick` |
| **代码位置** | `SearchRichItem.tsx:151` / `:237` |
| **行为** | 打开淘宝商品详情 iframe 浮层 |

**与PDD的区别**：
- PDD：悬停商品卡片后点击「查看商品详情」文字浮层
- 淘宝：商品卡片上有固定的跳转图标按钮，点击后显示 iframe

---

### ✅ 新增交互2：点击商品悬停浮层「查看商品详情页」

| 字段 | 内容 |
|------|------|
| **触发元素** | 商品卡片悬停浮层的「查看商品详情页」文字 |
| **事件** | `onClick` |
| **代码位置** | `SearchRichItem.tsx:156` / `:242` |
| **行为** | 在新标签页打开淘宝/天猫商品详情外部链接 |

**与PDD的区别**：
- PDD：悬停浮层打开内部详情浮层（在当前页面内展示）
- 淘宝：悬停浮层跳转外部详情页（打开新标签页）

---

### ✅ 新增交互3：点击 iframe 浮层的「关闭」按钮

| 字段 | 内容 |
|------|------|
| **触发元素** | iframe 商品详情浮层右上角的「关闭」按钮 |
| **事件** | `onClick` |
| **代码位置** | `SearchRichItem.tsx:348` |
| **行为** | 关闭当前展示的 iframe 商品详情浮层 |

**与PDD的区别**：
- PDD：详情浮层右上角有「×」关闭按钮
- 淘宝：iframe 浮层右上角有「关闭」文字按钮

**相似点**：两者都有关闭按钮，但展示形式和详情内容加载方式不同（PDD自定义详情页 vs 淘宝iframe嵌入）。

---

## 四、商品瀑布流 - 展示方式差异

### 商品详情展示方式不同

**淘宝**：
- 使用 **iframe** 嵌入淘宝/天猫移动端详情页
- iframe 覆盖在商品列表上方，不是弹窗模式
- 用户可以在 iframe 中滚动查看完整详情页

**拼多多**：
- 使用 **自定义详情浮层组件**（`detail.tsx`）
- 包含图片轮播、SKU选择面板等自定义交互
- 详情内容完全由前端组件渲染

---

## 总结

**淘宝与拼多多的核心交互差异**：

| 区域 | 淘宝 | 拼多多 |
|-----|------|--------|
| 筛选子选项面板关闭 | ✅ 有独立「×」按钮 | ❌ 只能点遮罩或重选标签 |
| 筛选弹窗关闭方式 | ✅ 顶部「×」关闭按钮 | ✅ 底部「确认」按钮 |
| 店铺卡片模块 | ✅ 有独立店铺卡片 | ❌ 无 |
| 商品详情展示 | ✅ iframe 嵌入外部页面 | ✅ 自定义详情浮层 |
| 商品跳转按钮 | ✅ 卡片上有固定图标 | ✅ 悬停显示文字浮层 |
| 详情关闭按钮 | ✅ 「关闭」文字按钮 | ✅ 「×」图标按钮 |
